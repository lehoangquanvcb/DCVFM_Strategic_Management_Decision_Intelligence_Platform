# DCVFM V3.3.10 — Reference ICB Sector Enrichment

## What changed
- Local Vnstock `Reference().industry.sectors()` mapping, with strict symbol/label detection, conflict removal and provenance.
- New `--sector-only` mode reuses existing `data_cache/silver_stock_snapshot.csv` and `silver_flow_snapshot.csv`. No repeated 1,401-stock price/fundamental crawl.
- New `--auto-sector` for future full refresh.
- Sector snapshot and quality metadata regenerated by existing `--repair-cache` logic.

## Cloud deployment
Push updated `refresh_silver_ai.py`, `sector_reference.py`, `app.py`, and **only those cache files whose publication is permitted under your Vnstock license**. Do not publish licensed data without authorization. Verify Streamlit Cloud is deploying the same repo and `main` branch. Reload/reboot app after deployment.

## Caveats
- Real Reference schema and subscription access have not been tested in the user's licensed environment. The adapter has a mocked API test only.
- `full_factor_ready` remains dependent on all factor coverage >=80%; sector mapping alone may not enable official recommendations.
- Existing mapping is preserved if Reference request fails.
